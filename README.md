# Inventory Stock Manager

A Python-based inventory management application for tracking products, quantities, and prices.

## Features

- Add products
- View inventory
- Search products
- Update stock quantities
- Delete products
- Calculate total inventory value
- JSON data storage

## Technologies Used

- Python
- JSON
- File Handling

## How to Run

1. Clone the repository.

2. Open the project folder.

3. Run:

```bash
python inventory.py
